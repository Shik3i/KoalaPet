# Habitat Customization

Customization is a progression pillar and functional environment, not superficial decoration. A habitat can layer background, ground strip, left/right structure, large furniture, small props, care stations, ambient effects, lighting/time variant, trophies, and pet interaction points.

Themes unlock through dungeons, achievements, crafting, shop/Trading Post, and progression. Components are generally mixable rather than locked to full matching sets. Content defines compatible modes, anchor/bounds metadata, interaction roles, unlock IDs, and assets.

Small Mode presents a dense but readable personal habitat. Expanded Mode provides editing and later farm context. Minimal Mode omits the habitat and shows only the pet/transient effects.

No generic RPG tileset dependency is assumed. Prefer generated full/layered backgrounds and modular transparent props. Free placement versus invisible grid is open and must be prototyped for keyboard/mouse accessibility, collision, small-window precision, and stable save serialization.
