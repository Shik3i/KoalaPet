# Neutral Example Pack

Architecture fixture for draft content API `0.1`. Everything is invented and intentionally generic. It demonstrates one starter egg, a family with branching good-care/high-care-mistake forms, separated preview/portrait/world assets, an item, move, encounter, dungeon, habitat theme, station, farm job, and feature gate.

Paths below `assets/placeholders/` are declared placeholders; no art is bundled. The validator verifies their safe normalized form but intentionally does not require placeholder files.
