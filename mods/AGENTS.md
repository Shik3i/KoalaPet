# Mod Agent Rules

Obey root `AGENTS.md`. Treat packs as untrusted data. Keep content API versions, namespaced IDs, localization, explicit overrides, deterministic ordering, dependency/reference validation, path normalization, and missing-content save recovery intact. Initial mods contain JSON and allowlisted safe media only—never scripts or native/executable payloads.

Example content must remain invented, neutral, clearly non-product, and free of third-party franchise terminology/assets. Run the content validator after every schema or fixture change.
