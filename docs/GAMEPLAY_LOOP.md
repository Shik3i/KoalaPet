# Gameplay Loop

## Opening loop

1. Choose one egg from a pack-defined starter pool.
2. Hatch and name one pet instance.
3. Observe attention calls and rhythms rather than manage every value constantly.
4. Feed, clean, rest, treat, train, play, and respond to behavior.
5. Take short battles that affect experience, history, win ratio, injuries, and possible evolution inputs.
6. Reach a branching lifecycle transition based on declarative history.

Basic food, cleaning, sleep, and basic treatment remain available without currency. Premium consumables and convenience may use progression resources.

## Expansion loop

Dungeons add encounter sequences, events, bosses, and cross-system rewards. Rewards personalize the habitat and widen care/adventure choices. A mature pet can eventually settle safely, enabling a second egg and revealing the farm/sanctuary only when it serves a real purpose. Residents contribute deterministic offline work while remaining identifiable and recallable. Trading Post orders create keep/process/sell decisions.

## Cadence principles

- Frame rate never controls balance.
- Important calls are legible and have fair response windows.
- Closing the game cannot create unbounded punishment.
- Offline progress is timestamp-based, capped, deterministic, and profile/tuning driven.
- Poor outcomes create alternate content, recovery, or intentional challenges rather than disposable pets.
