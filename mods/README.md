# Data-and-Asset Mods

Initial packs use JSON content API `0.1` and safe media. See `docs/MODDING.md`, `docs/CONTENT_MODEL.md`, `docs/SECURITY_AND_MOD_SAFETY.md`, and `schemas/`.

`examples/example.neutral/` demonstrates structure and cross-references only. Its identifiers, names, numbers, and placeholder asset paths are not official content or final balance.

The runtime external root defaults to `user://mods/`. Repository examples are injected as development fixtures and never bundled as production content.
