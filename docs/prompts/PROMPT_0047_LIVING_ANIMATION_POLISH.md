# Prompt 004.7 — Living Animation Expansion

## Scope

Expand the existing Milestone-4 product presentation without adding Milestone-5 gameplay. Replace two-pose animation placeholders with coherent multi-frame idle, care, sleep, combat and reaction sequences; add data-defined family effects, bounded ambient habitat life, richer Minimal behavior, Reduced Motion alternatives, native Windows evidence, performance measurements and complete validation.

## Implemented

- 29 animations for each of nine playable forms; five combat/reaction animations for each of four current enemies.
- Marker-aware bounded animation queue, authoritative-loop return, hidden-node suspension and null/type guards.
- Moss/Ember/Tide VFX profiles, effect preferences, hit feedback and data-defined prop interactions.
- Deterministic idle/roaming/playful scheduling, cursor attention and click reaction in Minimal.
- Native Godot Movie Writer review, bounded frame extraction, contact sheets, reels and eight-scenario performance evidence.
- Expanded validation for geometry, alpha, frame uniqueness, markers, coverage, content limits and presentation behavior.

## Explicit boundaries

- No habitat editor, furniture placement, farm, residents, jobs, trading, economy or second active pet.
- Generated art remains provisional and unlicensed pending product-owner/legal approval.
- Native evidence covers the recorded Windows 11 host only; macOS/Linux overlay parity and formal accessibility acceptance remain open.
