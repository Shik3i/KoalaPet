# KoalaPet

KoalaPet is a replaceable codename for a Windows-first, local-first desktop virtual-pet game. One personally raised companion begins in a classic care loop, then the same persistent simulation gradually opens into branching evolution, dungeons, habitat customization, collection, and farm/idle progression.

The project is in **Prompt 1 / desktop-overlay technical validation**. The supplementary macOS pass is recorded; the binding Windows validation remains blocked. There is no playable build or implemented pet simulation yet.

## Product pillars

- **Minimal:** a transparent, pet-only desktop companion with transient feedback.
- **Small:** the default compact, movable habitat window with quick actions.
- **Expanded:** an optional, practical management view; not a permanent full-screen takeover.
- **One simulation:** all three modes present the same authoritative state.
- **Classic V-pet first:** the farm and collection systems appear only after they have a purpose.
- **Data-driven and moddable:** bundled original content uses the same versioned registry as external data-and-asset packs.

Current direction: Godot 4.x, GDScript, Windows 10/11 first, Python validation tools, local saves, no accounts or telemetry. The official project contains only original, legally independent content; third-party franchise assets and terminology are not bundled or linked.
